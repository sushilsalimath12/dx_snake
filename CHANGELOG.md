# Changelog

All notable changes to `DX Snakes` are documented in this file.

## 0.2.3

- Added command aliases and startup activation hardening.
- Improved command discoverability and fallback behavior.
- Added status bar launcher for quick game access.
- Updated author/support metadata for Marketplace.
- Refined rendering and gameplay tuning.

## 0.2.2

- Added auto-open behavior and status bar play action.
- Improved command menu contributions.

## 0.2.1

- Added workspace capability support for trusted/untrusted and virtual workspaces.

## 0.2.0

- Tightened snake/frog segment spacing to near-continuous look.
